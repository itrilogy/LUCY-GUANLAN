# 双色球市场分析系统 安装部署手册

**软件全称：双色球市场分析系统 V1.0**

---

## 1 环境要求

| 项目 | 最低 | 推荐 |
|------|------|------|
| CPU | 双核 | 四核 |
| 内存 | 2GB | 8GB |
| 磁盘 | 500MB | 2GB+（含全量数据与备份） |
| OS | macOS 12 / Ubuntu 20.04 / Win10 | macOS / Ubuntu 22.04 |
| Python | 3.10 | 3.11+ |
| 浏览器 | 近两年 Chrome/Edge/Safari | 最新稳定版 |

网络：仅「数据更新」需要访问公开开奖数据源。

---

## 2 安装步骤

### 2.1 解压/获取代码

```bash
cd /path/to
# 解压发行包或 git clone
cd ssq_predictor
```

### 2.2 虚拟环境（推荐）

```bash
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -U pip
pip install -r requirements.txt
```

### 2.3 初始化数据

若发行包已含 `data/ssq_all.json`：

```bash
python3 scripts/init_data.py
python3 scripts/init_db.py    # 如需重建 SQLite
```

若仅有空数据，需联网：

```bash
python3 scripts/cli.py update --data-only
```

### 2.4 启动

```bash
make serve
# 或
python3 scripts/cli.py serve
```

访问：`http://localhost:8080`

### 2.5 生产部署（可选）

```bash
# 单 worker
gunicorn -w 1 -b 0.0.0.0:8080 app:app
```

反向代理（Nginx）可将 `/` 转到上述端口；静态文件由 Flask 提供，或单独挂载 `web/static`。

## 3 配置项

主要文件：`config.py` 或环境变量。

| 配置/环境变量 | 含义 | 默认 |
|---------------|------|------|
| `PORT` | 服务端口 | 8080 |
| `HOST` | 监听地址 | 0.0.0.0 |
| `STARTUP_FETCH` | 启动是否自动爬取 | auto |
| `SSQ_SCORING_MODE` | legacy/multi/dual | legacy |
| `SSQ_ALLOW_EXPERIMENTAL_SCORING` | 实验评分闸 | 未设置=关闭 |

---

## 4 日常运维

| 操作 | 命令 |
|------|------|
| 健康检查 | `make check` |
| 更新数据+预测 | `make update` |
| 仅预测 | `make predict` |
| 自动化测试 | `make test` |
| 评估冒烟 | `make eval` |

备份：复制整个 `data/` 目录。

---

## 5 升级

1. 停止服务  
2. 备份 `data/`  
3. 替换代码目录（保留 data）  
4. `pip install -r requirements.txt`  
5. `make check && make serve`  

若存在 DB 结构变更，按版本说明执行迁移脚本。

---

## 6 回滚

1. 停止服务  
2. 恢复上一版本代码与对应 `data/` 备份  
3. 启动并 `make check`  

---

## 7 故障排查

| 现象 | 处理 |
|------|------|
| 端口占用 | 修改 `config.PORT` 或结束占用进程 |
| 依赖冲突 | 使用干净 venv |
| 爬取失败 | 检查网络/代理；使用本地数据 |
| 页面无样式/无 LOGO | 确认 `web/static/brand` 完整 |
| SQLite locked | 避免多进程写；使用 gunicorn `-w 1` |

---

## 8 卸载

停服务 → 删除安装目录与 venv → 可选卸载全局 pip 包。
