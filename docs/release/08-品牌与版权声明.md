### 使用规范（遵循 LUXI Design §1.3 标识红线）

1. **界面双层化**：产品界面仅允许出现“产品方标”与“实验室符号标”，写实主标严禁出现在产品顶栏、页脚及 README 双标位。  
2. **符号标无方框**：实验室符号标本身不含方框底板，依靠与底材形成的差异色自然成立（浅底用绿、深底用金、绿底用白）。  
3. **双标等大**：README 与关于页中，产品方标与实验室符号标并排等大（64×64 或 48×48），不得一大一小。  
4. **诚实原则与口径**：预测及分析界面必须标注置信度与统计口径，严格声明“非中奖预言”。
