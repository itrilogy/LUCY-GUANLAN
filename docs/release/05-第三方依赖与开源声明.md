## 1 直接依赖（requirements.txt）

| 组件 | 典型用途 | 许可证（以包元数据为准） |
|------|----------|--------------------------|
| Flask | Web 框架 | BSD-3-Clause |
| APScheduler | 定时任务 | MIT |
| requests | HTTP 客户端 | Apache-2.0 |
| beautifulsoup4 | HTML 解析 | MIT |
| numpy | 数值计算 | BSD |
| scipy | 科学计算 | BSD |
| scikit-learn | 聚类/回归 | BSD-3-Clause |
| pytest | 测试（开发） | MIT |

安装时请执行：

```bash
pip install -r requirements.txt
pip show flask apscheduler requests beautifulsoup4 numpy scipy scikit-learn
```

以当前环境 `pip show` / 官网许可证文件为准；上表为常见情况，**不构成法律意见**。

## 2 间接依赖

Python 包管理器会安装传递依赖（如 Werkzeug、Jinja2、joblib、threadpoolctl 等）。  
完整清单生成方法：

```bash
pip freeze > THIRD_PARTY_FREEZE.txt
# 或
pip-licenses --format=markdown > THIRD_PARTY_LICENSES.md   # 需另装 pip-licenses
```

发行正式版建议附带 `THIRD_PARTY_FREEZE.txt` 快照。
