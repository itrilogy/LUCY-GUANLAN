## 5 安装与验收

安装步骤见《02-安装部署手册》。  
最低验收：

1. `pip install -r requirements.txt` 成功  
2. `make check` 通过  
3. `make serve` 后浏览器可打开主页  
4. 「快速」可生成推荐列表  
5. 页脚可见实验室主 LOGO
