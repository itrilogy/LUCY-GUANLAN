# 双色球预测分析工具 · 使用说明书

## 简介

本工具通过对双色球历史数据的多维度分析，提供:
- **宏观市场状态**: 当前处于蓄水/平衡/放水哪个阶段
- **号码区间画像**: 下一期号码特征的概率区间
- **推荐号码**: 经双向一致性验证的候选号码组合
- **号码热度**: 基于彩民行为反推的热门/冷门号码

## 安装

```bash
# 1. 安装依赖
pip install flask apscheduler requests beautifulsoup4 numpy scipy scikit-learn

# 2. 启动服务
cd ssq_predictor
python3 app.py

# 3. 打开浏览器访问
# http://localhost:8080
```

启动后将自动:
1. 加载 3481 期历史数据并预计算特征
2. 运行首次预测 (约10秒)
3. 注册每日 00:00 自动更新定时器
4. 在终端输出 "启动服务: http://0.0.0.0:8080"

## 页面功能

### 宏观仪表盘 (Dashboard)
- **市场状态进度条**: 从"蓄水"到"放水"的当前位置 (红色=放水, 橙色=平衡, 蓝色=蓄水)
- **奖池**: 当前奖池金额 (亿) + 下期预测范围
- **投注额**: 当前总投注额 (亿) + 下期预测范围
- **Regime**: 当前市场 Regime 编号 + 历史占比

### 预测号码列表 (Predictions)
- **推荐组合**: Top-10 经双向验证的号码组合
- **一致性评分**: 0~100%, 越高表示该号码在当前市场状态下越"自洽"
- **庄家成本分**: 正=热门(多人买), 负=冷门(少人买)
- **预期头奖注数**: 如果开出这组号码的估算头奖数
- **互逆校验状态**: ✅ 通过(评分>20%) / ⚠ 低分

### 号码热度 (Popularity)
- **热门号**: 基于遗漏值、近期频率、趋势和生日号效应的综合评分前10
- **冷门号**: 综合评分后10
- **生日号效应**: 1-31号段开出时头奖是32-33的倍数 (历史 1.16x)

### 上期回顾 (Review)
- 显示最新一期的实际开奖号码
- 与上期推荐的号码对比

## API 接口

```json
{
  "data_version": "26084",
  "last_update": "2026-07-25 00:00:00",
  "predict_ready": true,
  "total_draws": 3481

```

### GET /api/predict
返回最新预测结果 (完整报告结构):
| 字段 | 说明 |
|------|------|
| current_issue | 最新期号 |
| market.regime | 市场状态 "蓄水/平衡/放水" |
| market.regime_id | Regime编号 0~4 |
| market.pool | 当前奖池 (元) |
| market.bet | 当前投注 (元) |
| market.predicted_pool_range | [下界, 上界] 奖池预测区间 |
| market.predicted_bet_range | [下界, 上界] 投注预测区间 |
| predictions[].reds | 推荐红球 [6个] |
| predictions[].blue | 推荐蓝球 |
| predictions[].consistency | 一致性评分 0~1 |
| predictions[].cost | 庄家成本分 |
| predictions[].est_prize1 | 预期头奖注数 |
| predictions[].passed | 是否通过校验 |
| popularity.hot | 热门号Top10 |
| popularity.cold | 冷门号Top10 |
| popularity.birthday_effect | 生日号效应量 |
| last_review.actual_reds | 上期实际红球 |
| last_review.actual_blue | 上期实际蓝球 |

### GET /api/update
手动触发预测更新:
```json
{"success": true, "time": "2026-07-25 23:00:00"}
```

## 指标解读

| 指标 | 含义 | 取值范围 | 如何解读 |
|------|------|---------|---------|
| 一致性评分 | 前向推演与反向验证的匹配度 | 0~100% | 高≠中奖概率, 仅表示"自洽" |
| 成本分 | 该号码组合的"庄家成本" | -∞~+∞ | 正=多人买, 负=少人买 |
| 市场状态 | 当前奖池/投注/头奖所处阶段 | 蓄水/平衡/放水 | 决定号码策略倾向 |
| Regime | 市场模式的GMM聚类编号 | 0~4 | 用于内部状态转移预测 |
| 生日号效应 | 1-31号段 vs 32-33的差异倍数 | ~1.16 | 彩民偏好小号的量化 |

## 定时更新机制

系统使用 APScheduler 实现每日自动更新:
- **触发时间**: 每日 00:00 (可配置 config.py 中的 UPDATE_HOUR/UPDATE_MINUTE)
- **更新内容**: 爬取500.com最新数据 → 重算特征 → 重跑预测 → 更新结果文件
- **容错**: 更新失败不阻断服务, 保留上次预测结果
- **启动时**: 首次启动立即执行一次完整预测

## FAQ

**Q: 推荐号码能保证中奖吗?**
A: 不能。所有统计检验 (卡方检验、游程检验、累积量检验、自相关分析) 均表明号码是独立随机过程。推荐号码是"在当前市场条件下最自洽"的组合。

**Q: 一致性评分高是什么意思?**
A: 表示该号码组合通过了前向(→估算头奖)和反向(头奖→推状态)的双向校验, 在数学上自洽。评分高不说明该号码"更可能中", 只说明它"在当前市场状态下合理"。

**Q: 数据多久更新一次?**
A: 每日 00:00 自动爬取最新一期数据并重新预测。也可以随时点击 /api/update 或运行 python3 scripts/crawl_update.py 手动更新。

**Q: 全量进化模式是什么?**
A: 勾选 "🧬全量进化" 复选框后，推理会先运行 30 代遗传进化（~12分钟），产出最佳权重后再进行预测。不勾选时使用缓存权重（~2秒快速预测）。

**Q: 可以预测大乐透吗?**
A: 当前版本仅支持双色球。大乐透需在 config.py 中配置 DLT_URL 并扩展 DataHub.

**Q: 服务端口被占用了怎么办?**
A: 在 config.py 中修改 PORT 变量 (默认8080)。macOS 用户注意 5000 端口可能被 AirPlay 占用。

**Q: 模型准确率如何?**
A: 历史回测显示 top-1 推荐平均命中 0.6~1.2 个红球 (随机期望 6/33*6=1.09)。一致性评分与实际命中率之间存在弱正相关。

**Q: 代码中为什么有 numpy JSON 编码器?**
A: 因为 scikit-learn 和 numpy 返回的数据类型 (np.float64, np.int64, np.bool_) 不是 Python 原生类型, json.dump 无法直接序列化。NumpyEncoder 类负责自动转换。

## 故障排除

| 问题 | 可能原因 | 解决 |
|------|---------|------|
| 启动报错 "Port in use" | 端口被占用 | 修改 config.py 中 PORT |
| 页面显示无数据 | 首次加载未完成 | 刷新页面, 等待10秒 |
| API 返回 500 | numpy类型错误 | 检查 predict_result.json 是否损坏, 删除后重启 |
| 预测结果不变 | 500.com 当天未开奖 | 正常, 跳过更新 |
