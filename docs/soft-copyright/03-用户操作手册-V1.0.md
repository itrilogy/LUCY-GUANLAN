## 1 软件概述

### 1.1 软件简介

双色球市场分析系统是一套基于 Web 的本地化数据分析软件。系统对公开双色球历史开奖及奖池、投注、奖级相关数据进行分析与可视化，生成候选号码组合供研究参考，并给出市场状态、结构与一致性等指标说明。

### 1.2 适用范围

- 历史开奖数据整理与浏览  
- 市场状态（奖池水位、投注水平、状态聚类）观察  
- 候选组合的结构与一致性研究  
- 教学、统计演示与方法对比  

**不适用：** 博彩投注下单、保证中奖、投资理财建议。

### 1.3 运行环境

见《02-软件功能与特点说明》第四节。推荐内存 ≥4GB，磁盘预留 ≥200MB。

### 1.4 界面语言

简体中文。

## 2 安装与启动

### 2.1 获取软件

从发行包解压得到 `ssq_predictor` 目录（或从源码仓库检出该目录）。

### 2.2 安装依赖

在软件根目录执行：

```bash
cd ssq_predictor
pip install -r requirements.txt
```

### 2.3 启动服务

```bash
make serve
# 或
python3 scripts/cli.py serve
```

默认监听 `http://0.0.0.0:8080`。在浏览器地址栏输入：

```
http://localhost:8080
```

### 2.4 首次启动说明

- 系统加载本地历史数据并初始化分析模型。  
- 若配置为自动检查更新，可能在后台尝试连接公开数据源；失败时不影响使用本地已有数据。  
- 页面顶部显示产品标识与鹿溪联合实验室出品标识。

### 2.5 停止服务

在运行服务的终端中按 `Ctrl+C` 结束进程。

## 3 主界面说明

### 3.1 页面布局

主界面为单页应用，自上而下主要包括：

1. **顶栏**：产品名称、实验室标识、状态摘要、操作按钮  
2. **声明条**：方法边界与免责提示  
3. **标签页**：推理/推荐、历史趋势、预测对照等（以实际界面标签为准）  
4. **内容区**：推荐号码、复式方案、图表与表格  
5. **页脚**：实验室主 LOGO、数据来源与版本信息  

### 3.2 顶栏按钮

| 按钮 | 功能 |
|------|------|
| ▶ 快速 | 使用当前数据与默认权重，快速生成分析报告 |
| 🧬全量(研究) | 启用遗传进化搜索权重后再分析（研究用，耗时较长） |
| 📥更新 | 爬取最新开奖数据并重新分析 |
| 💾保存 | 将当前推荐写入对照表，便于日后核对 |

### 3.3 进度条

操作执行时，进度条与文字提示当前阶段（采样、验证、报告等）。完成后恢复为「就绪」。

## 4 功能操作说明

### 4.1 查看市场状态

1. 打开主页，等待加载完成。  
2. 在顶部卡片或市场信息区查看：奖池、投注、市场水位（蓄水/平衡/放水）、状态编号等。  
3. 报告中的「预测奖池/投注区间」为模型估算区间，供趋势参考。

### 4.2 快速生成推荐组合

1. 点击 **▶ 快速**。  
2. 等待进度完成。  
3. 在推荐列表中查看排序后的红球、蓝球及评分指标。  

**指标说明（默认模式）：**

| 展示项 | 含义 |
|--------|------|
| 自洽 / 一致性 | 前向与反向校验的匹配程度，**不是中奖概率** |
| 成本 | 组合在「热门/冷门」结构上的成本分 |
| 头奖注数估算 | 若该组合开出时，模型估计的头奖注数量级 |

### 4.3 复式方案查看

1. 在快速分析完成后，下拉查看「复式推荐」区域。  
2. 不同档位给出红球集合、蓝球集合、注数与金额估算。  
3. 「高频聚合」为基于 Top 推荐的频次汇总，标注为频次参考。

### 4.4 更新数据

1. 确认运行环境可访问公开数据源（如 500.com 历史页）。  
2. 点击 **📥更新**。  
3. 系统爬取、合并本地库并重跑分析。  
4. 顶栏状态显示最新期号与完成提示。

也可使用命令行：

```bash
make update
# 仅数据
make data-only
```

### 4.5 全量进化（研究）

1. 点击 **🧬全量(研究)**。  
2. 系统进行多代遗传搜索（可能数分钟至十余分钟）。  
3. 完成后用得到的权重生成推荐。  

说明：该过程优化的是**一致性相关目标**，界面已提示「研究用、非命中优化」。

### 4.6 保存预测对照

1. 生成推荐后点击 **💾保存**。  
2. 系统写入数据库批次与明细。  
3. 在「预测对照」类页面/区域查看历史保存记录及开奖后命中回填（若已开奖）。

### 4.7 历史趋势与期号浏览

1. 切换至历史/趋势相关标签。  
2. 查看红蓝球频率、奖池曲线、分区等图表。  
3. 在期号表中分页浏览历史开奖号码。

### 4.8 命令行常用操作

| 命令 | 说明 |
|------|------|
| `make check` | 数据校验 + 引擎冒烟 |
| `make predict` | 本地重跑预测 |
| `make test` | 自动化测试 |
| `make eval` | walk-forward 冒烟评估 |

## 5 实验模式（可选，默认关闭）

高级用户可通过环境变量启用多目标排序：

```bash
export SSQ_ALLOW_EXPERIMENTAL_SCORING=1
export SSQ_SCORING_MODE=multi
make serve
```

浏览器控制台可设置 `window.SSQ_MODE='multi'` 后点击「快速」。  
多目标模式下列表可显示：抗拥挤、结构、市场拟合、final 等分项（仍非中奖概率）。

## 6 数据说明

### 6.1 数据来源

默认公开来源为双色球历史开奖信息页（配置项中的 URL）。用户应遵守数据源网站的使用条款。

### 6.2 本地存储位置

| 路径 | 内容 |
|------|------|
| `data/ssq_all.json` | 全量历史 JSON |
| `data/ssq.db` | SQLite（开奖与预测对照） |
| `data/predict_result.json` | 最近一次分析报告 |
| `web/static/brand/` | 品牌与图标资源（完整自包含） |

### 6.3 备份建议

发行与生产使用前，请定期备份 `data/` 目录。

## 7 常见问题

**Q1：页面打不开？**  
检查服务是否已启动、端口 8080 是否被占用、防火墙是否拦截。

**Q2：更新失败？**  
检查网络、数据源是否可访问；可先 `make check` 使用本地数据。

**Q3：一致性很高是否表示容易中奖？**  
否。一致性仅表示模型内部前向/反向关系是否自洽。

**Q4：能否保证推荐命中？**  
不能。号码开奖接近随机，本软件不作任何中奖承诺。

**Q5：依赖安装失败？**  
确认 Python 版本 ≥3.10，使用虚拟环境后重试 `pip install -r requirements.txt`。
