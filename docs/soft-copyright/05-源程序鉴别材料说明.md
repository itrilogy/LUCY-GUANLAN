## 1 摘录规则（实务常用）

| 规则 | 建议 |
|------|------|
| 页数 | 前 30 页 + 后 30 页（合计约 60 页）；总行数不足则全部提交 |
| 每页行数 | 约 50 行源代码 |
| 页眉 | **双色球市场分析系统 V1.0** + 页码 |
| 顺序 | 连续页码；最后一页应为某完整模块/文件自然结束 |
| 内容 | 须与说明书功能对应，含核心业务代码，而非仅依赖库 |

---

## 2 建议摘录文件顺序（前部）

按依赖与入口优先：

1. `config.py`  
2. `app.py`（入口与路由，可截取前部）  
3. `engine/data_hub.py`  
4. `engine/crawler.py`  
5. `engine/market.py`  
6. `engine/numbers.py`  
7. `engine/validator.py`  
8. `engine/predictor.py`  

## 3 建议摘录文件顺序（后部）

从仓库尾部模块向前取满约 30 页：

1. `engine/ranker.py`  
2. `engine/behavior.py`  
3. `engine/evolution.py`  
4. `engine/eval/walk_forward.py`  
5. `scripts/cli.py`  
6. `web/templates/index.html`（可作辅助，以 .py 为主更稳妥）  

> 以实际导出页数为准，保证「前连续 + 后连续」。

## 4 一键生成鉴别材料草稿（可选脚本）

在 `ssq_predictor` 目录执行（生成纯文本，再导入 Word 设页眉页脚）：

```bash
python3 << 'EOF'
import os
from pathlib import Path
ROOT = Path('.')
files_head = [
    'config.py', 'app.py',
    'engine/data_hub.py', 'engine/crawler.py', 'engine/market.py',
    'engine/numbers.py', 'engine/validator.py', 'engine/predictor.py',
]
files_tail = [
    'engine/ranker.py', 'engine/behavior.py', 'engine/evolution.py',
    'engine/eval/walk_forward.py', 'scripts/cli.py',
]
out = Path('docs/soft-copyright/generated')
out.mkdir(parents=True, exist_ok=True)

def dump(paths, name):
    lines = []
    for p in paths:
        fp = ROOT / p
        if not fp.exists():
            continue
        lines.append(f"# ===== FILE: {p} =====")
        for i, row in enumerate(fp.read_text(encoding='utf-8', errors='replace').splitlines(), 1):
            lines.append(row.rstrip())
        lines.append("")
    (out / name).write_text("\n".join(lines), encoding='utf-8')
    print(name, 'lines', len(lines))

dump(files_head, 'source_head.txt')
dump(files_tail, 'source_tail.txt')
print('→ docs/soft-copyright/generated/')
EOF
```

然后：

1. 用编辑器/Word 打开 `source_head.txt` / `source_tail.txt`  
2. 设置字体（如宋体/Courier 9pt）、页边距，使约 50 行/页  
3. 页眉：**双色球市场分析系统 V1.0**  
4. 从 head 取前约 30 页，从 tail 取后约 30 页，合并为 PDF
