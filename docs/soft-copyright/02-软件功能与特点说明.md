# 软件功能与特点说明

**软件全称：双色球市场分析系统**  
**版本号：V1.0**

（本文件供软著申请表「主要功能」「技术特点」栏摘录使用，可整段或缩写提交。）

---

## 一、开发目的

本软件面向公开可获取的双色球历史开奖及市场相关数据，提供采集更新、本地存储、统计分析、候选组合生成与结果展示等功能，用于研究奖池、投注额、头奖注数等**市场状态**与号码组合的**结构特征**。软件不提供博彩投注下单，不对开奖结果作出保证。

---

## 二、主要功能（可粘贴精简版）

1. **历史数据管理**  
   支持从公开数据源获取双色球历史开奖信息，合并写入本地 JSON 与 SQLite 数据库，并进行期号校验与完整性检查。

2. **市场状态分析**  
   基于奖池、投注额、头奖注数等变量进行状态聚类与水位分级，展示市场 regime 分布及简单反馈关系（如奖池与投注的相关关系分析）。

3. **号码特征与成本分析**  
   对红球、蓝球及相关结构特征（和值、跨度、分区、连号、生日号等）进行统计描述；提供组合「成本/拥挤度」类评分用于研究人群偏好结构。

4. **候选组合生成与双向校验**  
   按设定条件采样候选红蓝球组合，通过前向估算与反向邻域检索形成一致性评分，并对结果排序展示。

5. **多目标排序（可选实验模式）**  
   在实验开关开启时，支持按抗拥挤、结构拟合、市场拟合等维度综合排序，默认模式保持传统一致性排序。

6. **复式方案辅助规划**  
   基于验证通过的候选池，生成不同档位的复式覆盖方案及组合注数、金额估算展示。

7. **Web 可视化界面**  
   提供浏览器访问的单页分析界面，包括推荐列表、复式方案、历史趋势图、分区与期号浏览、预测对照保存等。

8. **定时与手动更新**  
   支持开奖日后自动调度更新及用户手动触发数据爬取与分析刷新；提供命令行工具完成检查、预测与评估冒烟。

9. **评估与进度反馈**  
   提供 walk-forward 类冒烟评估输出与前端进度条，便于检验流程是否跑通。

## 三、技术特点（可粘贴精简版）

1. **B/S 本地部署架构**  
   后端采用 Python Flask 提供 HTTP 服务与 API，前端为静态页面 + 模板渲染，用户通过浏览器访问，无需安装客户端。

2. **统一数据中枢**  
   DataHub 统一加载历史数据，预计算号码特征、市场变量与画像，并同步 SQLite 以加速按头奖注数等条件的查询。

3. **增量数据合并**  
   支持远端拉取与本地按期号合并，自动回填预测对照命中字段，减少全量重采成本。

4. **模型分层设计**  
   市场模型（GMM/转移/回归）、号码与行为模型、验证器、排序器、预测编排分层实现，便于维护与扩展。

5. **进程内软更新与全量重训**  
   服务进程可在新增期次时对聚类标签做软扩展，并按周期触发全量重拟合；命令行更新始终全量重建以保证一致性。

6. **鉴别材料友好的纯 Python 实现**  
   核心逻辑以 Python 实现，依赖常见科学计算与 Web 库，源程序可读性好，便于按规定摘录鉴别材料。

7. **品牌资源本地自包含**  
   产品图标与实验室标识文件完整存放于软件静态资源目录，运行不依赖外部网络图床。

## 四、运行环境摘要

| 类别 | 要求 |
|------|------|
| 操作系统 | macOS 12+ / Ubuntu 20.04+ / Windows 10+（推荐类 Unix） |
| 运行时 | Python 3.10 及以上 |
| 主要依赖 | Flask、APScheduler、NumPy、SciPy、scikit-learn、requests、BeautifulSoup4 |
| 浏览器 | Chrome / Edge / Safari 近两个大版本 |
| 网络 | 数据更新时需可访问公开数据源；纯本地分析可不联网 |

## 五、模块组成

| 模块 | 说明 |
|------|------|
| 数据层 DataHub / Crawler | 加载、爬取、合并、SQLite |
| 市场 MarketModel | Regime、反馈、Markov、投注/头奖估计 |
| 号码 NumberModel / BehaviorModel | 特征、采样、成本、拥挤 |
| 验证 Validator | 前向/反向、LUT、批量校验 |
| 排序 Ranker | 多目标 final（实验） |
| 编排 Predictor | 流水线与报告 |
| 进化 Evolution | 可选研究用权重进化 |
| Web app / CLI | 服务入口与运维命令 |
